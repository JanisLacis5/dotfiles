# Developer Profile

- C/C++ Linux systems engineer.
- Primarily interested in Linux kernel networking, drivers,
  concurrency, and low-level systems programming.
- Prefer C over C++ where appropriate.

# Engineering Preferences

- Prefer minimal, idiomatic solutions over elaborate abstractions.
- Preserve spacing between logical code blocks.
- Avoid unnecessary classes, wrappers, and dependencies.
- Investigate existing code and established patterns before changes.
- Prioritize correctness, ownership, and lifetime safety.
- Do not modify unrelated code.
- Explain design decisions rather than merely presenting code.
